Website portfolio pribadi yang dibuat untuk menampilkan profil, pengalaman, keterampilan, sertifikat, dan informasi kontak dalam satu platform digital yang responsif dan modern. 
Website ini dirancang sebagai media personal branding untuk memperkenalkan diri secara profesional kepada recruiter, dosen, organisasi, maupun calon kolaborator.
struktur halaman: navigasi modern, bagian "about me", experience timeline, tools yang digunakan, galeri sertifikat, form kontak, dan social media integration
website ini merupakan integrasi dari penggunaan HTML5, Tailwind CSS, dan JavaScript
